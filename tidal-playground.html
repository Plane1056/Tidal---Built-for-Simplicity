Tidal Playground

Built for simplicity · basic 2D interpreter

Code

Supported Tidal syntax
washup 2D imports the environment.
spawn square scale (2) creates a square.
x 2, y 2, z 2 set the latest square's coordinates.
scale (3) changes its scale.
color blue or color #ff8844 changes its color.
Blank lines and // comments are allowed.

Prototype rules: x points right, y points up; z controls layering (larger values draw in front). One unit = 40 pixels. Scale 1 = a one-unit square. Each Run replaces the scene. Only 2D is implemented.
